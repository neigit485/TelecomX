Telecom X — Análise Completa de Evasão de Clientes (Churn)

Descrição
Projeto de análise exploratória e preparação de dados para entender os fatores associados à evasão (churn) de clientes na Telecom X.

Esta é a versão completa do projeto, contemplando:

ETL com pandas (foco principal)
Exploração univariada e bivariada
Análises multivariadas (combinações de contrato, internet, pagamento e tenure)
Segmentação de perfis de alto/baixo risco
Gráficos em português do Brasil (nomes de categorias e eixos)
Fonte de dados
Arquivo JSON disponibilizado pela Alura:
https://github.com/alura-cursos/challenge2-data-science/blob/main/TelecomX_Data.json

Como usar este notebook no Google Colab

Baixe o arquivo TelecomX_Data.json do GitHub da Alura (ou do seu repositório): https://github.com/alura-cursos/challenge2-data-science/blob/main/TelecomX_Data.json

No Google Colab, faça upload do arquivo TelecomX_Data.json para o diretório de trabalho:

Abra o painel “Arquivos” (ícone de pasta)
Clique em “Upload”
Selecione o arquivo TelecomX_Data.json
Execute as células do notebook na ordem.

Observação importante
O notebook tenta primeiro ler o arquivo local TelecomX_Data.json. Se não encontrar, faz fallback para a URL do GitHub. Isso ajuda a evitar erros caso o arquivo não tenha sido enviado para o Colab ainda.
